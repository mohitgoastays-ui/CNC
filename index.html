Five steps, one browser tab

From photo to machine-ready file in under a minute

📷

Drop your image

JPG, PNG, or WEBP. Everything stays local — your file never leaves your machine unless you ask for a heavy server job.

🎛️

Tune the depth

Brightness, contrast, gamma, black/white points, smoothing. Pixel brightness maps to carve depth — you control the curve, not an AI.

📐

Set stock and tools

Material dimensions, max carve depth, tool type (ball-nose, V-bit, flat), stepover, feeds and speeds. Depth is clamped to your real stock — no surprises at the machine.

⚙️

Generate toolpaths

Roughing + finishing as separate operations. Scallop height calculated live. Real-time 3D preview — orbit, zoom, switch views. All computed in your browser.

📥

Export and carve

G-code (GRBL / Mach3 / LinuxCNC), STL, OBJ, PLY, 3MF, glTF, SVG, DXF, depth PNG. Same input always produces byte-identical output.
